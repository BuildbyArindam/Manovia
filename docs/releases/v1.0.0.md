# Manovia v1.0.0 — first release

**Beta — portfolio demo, not a clinical service.** Manovia is a portfolio
project built in 30 days. It has not completed a clinical review
([docs/clinical-review.md](../clinical-review.md) has no sign-offs), its Hindi
and Bengali strings have not been reviewed by native speakers, and the
helpline file must be re-checked by a person before anyone in distress relies
on it. The app says all of this in its footer. Do not rely on Manovia for care.

## What Manovia is

A privacy-first, safety-first self-help companion for mental wellbeing, in
English, Hindi and Bengali. It is not therapy, not a diagnostic tool and not a
crisis service.

## Features

- **Supportive chat** with a rules-first safety pipeline: deterministic crisis
  detection runs *before* any language-model call; a high-risk message gets a
  pre-written, localised reply with helplines and the model is never called
  for it. Every model reply passes a deterministic output guard before it is
  stored or shown.
- **Safety detection**: a reviewable rules engine plus a one-way ML backstop
  that can raise the risk level but never lower it, with a session risk
  accumulator for slow multi-turn escalation.
- **Self-help tools**: mood check-ins, an encrypted journal, eight guided
  exercises, a seven-step CBT thought record, PHQ-9 and GAD-7 screenings
  (support options appear before any score when PHQ-9 item 9 is positive), a
  transparent rule-based daily plan, and insights.
- **Privacy controls**: export everything, delete everything, per-user
  retention; message text, journal entries and mood notes encrypted at rest;
  raw user text never logged; no identifiers sent to the model.
- **Offline and accessible**: an installable PWA where "Need help now" and the
  breathing exercises work with no connection; WCAG 2.2 AA as the target, with
  an in-app accessibility statement.

## Safety statement

Crisis and self-harm detection is deterministic and runs before any LLM call.
High-risk messages receive pre-written responses with helplines — the model
never improvises at high risk. Manovia never diagnoses, never discusses
medication doses, never claims to be a therapist or a human, and discloses its
AI nature in onboarding and settings. These rules are non-negotiable and are
enforced by tests and CI gates (`AGENTS.md`,
[docs/safety-design.md](../safety-design.md)).

**Limits of that statement:** detection is pattern-plus-ML over synthetic
datasets. A 1.000 recall on the evaluation splits is not a guarantee of zero
missed crises in the wild. The precision trade-off is deliberate: roughly
three in five crisis escalations on the dev split are false alarms, because
missing a real crisis is the worse error.

## Limitations (read before using)

- **No clinical review.** The crisis copy, helplines, knowledge base and
  screening presentation have not been reviewed by a licensed clinician.
- **Synthetic evaluation only.** All datasets are authored or generated; no
  real-user data. Emotion classification collapses on domain-shift phrasing
  (macro-F1 0.992 in-domain → 0.011 on implicit/somatic expressions).
- **Over-escalation is real and measured.** With the ML backstop on, benign
  texts such as recovery stories are escalated; precision on the dev split is
  0.543.
- **Hindi and Bengali are AI-produced drafts** (`translations/STATUS.md`);
  non-English crisis rules are not native-reviewed.
- **Helplines** carry `last_verified` dates and four entries are flagged
  `needs_verification`; a person must re-check the file before launch.
- **Real-provider behaviour is unmeasured** in CI; the suites run against a
  deterministic fake. Single-process limiters and session stores mean
  one worker per deployment for now.
