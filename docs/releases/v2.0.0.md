# Manovia v2.0.0 — portfolio demo, not a clinical service

Released 20 October 2026 · [CHANGELOG](../../CHANGELOG.md) · [Technical report](../technical-report.md) · [Verification](../verification/day49-verification.md)

> **This is a portfolio project.** Manovia is not therapy, not a diagnosis and
> not a crisis service. It has not been clinically reviewed, the Hindi and
> Bengali copy has not been reviewed by native speakers, and no real user has
> relied on it. If you are in danger or in crisis, call your local emergency
> number now (112 in India, 911 in the US and Canada, 999 in the UK, 000 in
> Australia).

v2.0 is the release where the project grew an ML platform, an on-device mode, and
the discipline to report what did **not** work. Every number below is produced by
a command in the repository and linked to the committed report that quotes it;
the full argument is in the [technical report](../technical-report.md).

## Highlights

### An ML platform, with gates rather than promises
`ml/` holds a licensed dataset catalogue (17 datasets, 10 restricted), DVC-versioned
splits whose manifests are byte-stable, config-validated reproducible training,
MLflow tracking (commit, data hashes, config, seed, library versions), and release
gates that **fail the build**: reproducibility against committed baselines, model
size and INT8 ratios, fairness across eleven identity dimensions, a differential-
privacy budget, and licence verdicts. `make ml-test` → **553 passed, 1 skipped**.

### Safety that keeps the rules in charge
Crisis rules still decide, deterministically, before any model call. The ML
backstop may only raise caution ([ADR 0009](../adr/0009-safety-ml-ensemble.md)).
On the 116-case dev split: **recall 1.000 [1.000, 1.000] at precision 0.543**;
rules alone 0.333. A high-risk message never reaches a language model.

### Private Mode: nothing leaves the device
The same normalisation, rules, escalation and output guard, compiled from the
same content to JavaScript, with **500/500 phrase parity** against Python and
**0 network requests** during a conversation. Replies come from templates in this
release, because no model weights are pinned (see “Known issues”).

### Research that reports its own negative result
- **Mood forecasting**: the best neural model (`transformer`, MAE 0.561) **lost**
  to a seven-day moving average (0.554) on held-out synthetic users. Not shipped;
  the product keeps the deterministic, opt-in descriptive range.
- **Contextual bandits**: LinUCB reward 193.795 [186.693, 200.897] vs random
  −73.388 in simulation, exploration capped at 20 % and never consecutive. Not
  shipped.
- **Federated learning with DP**: ε 0.8417 at δ 1e-5 in simulation, held-out MASE
  1.2754 vs centralised 1.3372. Not shipped.

### Retrieval you can measure
Hybrid BM25 + dense + cross-encoder with a calibrated “no good answer” floor:
**MRR 0.658, Recall@1 0.354** on a frozen 52-query split, for **+5.5 ms** p95
over the v1.0 baseline. The higher-MRR fine-tuned variant is measured and
deliberately not shipped, because it cannot abstain.

### Tools with a safety story
Real-time voice with barge-in (p95 first-audio 98.6 ms on fake stages), HRV-paced
breathing, a local personal-patterns graph, an agentic care navigator with
read-only tools and confirmation gating (**40/40** scenarios), generative calm
audio, a WebXR calm space with a 2D fallback and a sensory profile, and a
clinician-share bridge whose decryption key the server never holds (PDF + HL7
FHIR R4, expiring links, revocable, uniform 404s).

### Responsible AI as artefacts
A 21-risk register with gates, privacy-only drift monitoring, **12 kill switches**
that flip without a restart and are audited, a `/transparency` page (14
components × 5 headings, in English, Hindi and Bengali), and a red-team pass with
regression tests.

## Known issues

1. **Not clinically reviewed**; no native-speaker sign-off on Hindi or Bengali.
2. **Recall-first costs precision.** 31 of 51 benign dev cases escalate; in the
   live journey *“I had a long day and I am tired.”* produced the crisis card.
3. **No pinned on-device model.** `npm run models:pin` has never run, so Private
   Mode answers with templates everywhere.
4. **No Lighthouse or real-device performance numbers** for this release.
5. **Four helpline entries are still flagged `needs_verification`** (iCall, KIRAN,
   AASRA, Kids Helpline AU); all 34 entries were last verified on 2026-10-09.

## What a human must do before real users rely on this

Clinical review of the crisis copy, helplines and screening presentation ·
native-speaker review of Hindi and Bengali · ethics and legal review (age policy,
jurisdiction, consent) · a security review by someone who did not write it ·
user research with ethics approval · pinning and measuring an on-device model ·
a browser and real-device run of the E2E journeys and Lighthouse budgets.

## Upgrade notes

`alembic upgrade head` brings a v1.0 database to this schema (migrations 0009 →
0012). New configuration is optional; the two switches worth knowing are
`SHARE_ENABLED` (operator kill switch for the share bridge) and
`PRIVATE_LLM_MODEL_ID` (unset: Private Mode replies with templates). No model
identifier is required, and none is hard-coded.
