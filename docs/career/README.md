# Career material (Day 30)

Material for presenting the Manovia project in a job search. Deliberately
**not linked from the project README** — it is about the author, not the
product.

- [resume-bullets.md](resume-bullets.md) — five resume bullets; every number
  maps to a file in this repository (the mapping is in the file).
- [elevator-pitch.md](elevator-pitch.md) — a 2-minute spoken pitch.
- [linkedin-post.md](linkedin-post.md) — a launch post draft.
- [demo-video-script.md](demo-video-script.md) — a 90-second demo script
  (shot-by-shot; the product demo flow also exists at
  [../demo-script.md](../demo-script.md)).
- [interview-top-25.md](interview-top-25.md) — the top 25 interview questions
  about this project, with honest answers.

**v2.0 additions (Day 49)** — same house rule, and every number in them is
measured:

- [resume-bullets-v2.md](resume-bullets-v2.md) — ten bullets, each mapped to the
  command and report that produced its number, plus the phrases that were removed
  because they were not true.
- [pitch-2min.md](pitch-2min.md) — a two-minute spoken pitch with timings and the
  sentences to keep if you are cut off at 60 seconds.
- [walkthrough-5min.md](walkthrough-5min.md) — a five-minute technical walkthrough
  for a screen share, with the question each block invites.
- [blog-post-outline.md](blog-post-outline.md) — outline for *“The neural model
  lost to a moving average, and I shipped the moving average”*.
- [interview-deep-dive-30.md](interview-deep-dive-30.md) — 30 deep-dive questions
  with answers on model calibration, why rules first, conformal abstention,
  federated vs centralised, bandit safety constraints, privacy attacks,
  evaluation limits, and what would change with real clinical data.

House rule, same as the rest of the repository: no number appears here that
cannot be traced to an evaluation report, a test log, or a committed document.
